Zapasy w magazynie
W magazynie stoi n regałów ponumerowanych od 0 do n-1, na i-tym regale leży a_i paczek. Kierownik zadaje pytania:
ile paczek łącznie leży na regałach o numerach od l do r (włącznie)?
Wejście
Pierwszy wiersz zawiera liczbę n (1 ≤ n ≤ 200 000). Drugi wiersz zawiera n liczb a_0, a_1, ..., a_{n-1}
(0 ≤ a_i ≤ 10^9). W trzecim wierszu znajduje się liczba zapytań q (1 ≤ q ≤ 200 000). W każdym z następnych q wierszy
znajdują się dwie liczby l i r (0 ≤ l ≤ r ≤ n-1).
Wyjście
Dla każdego zapytania wypisz w osobnym wierszu łączną liczbę paczek na regałach od l do r.
Przykład
Dla danych wejściowych:
6
4 0 2 7 1 3
3
0 2
3 5
1 1
poprawnym wynikiem jest:
6
11
0
